# 什么是八字（四柱命理）？零基础入门指南

你是否觉得西方占星术无法完全诠释你的性格？或者你在寻找一种能像数学公式一样精确描绘你人生轨迹的体系？

欢迎来到**八字**（Bazi，八字），又称**四柱命理**（Four Pillars of Destiny）——这是一门拥有两千多年历史的中国传统术数，利用你的出生年月日时，揭示你的性格、天赋、挑战以及人生轨迹。

与西方占星术以行星位置为核心不同，八字的核心是**时间本身**——具体来说，是你出生的那个精确时刻，被拆解为四个柱（四柱）。

## 四柱详解

你的八字命盘由四柱组成，每柱代表你人生的不同面向：

| 柱 | 代表 | 年龄段 |
|--------|-----------|-----------|
| **年柱** | 祖业、家族背景、早年运势 | 15岁之前 |
| **月柱** | 父母、事业基础、青年时期 | 16–30岁 |
| **日柱** | **你自己**——核心性格、配偶、中年时期 | 31–45岁 |
| **时柱** | 子女、晚年运势、人生遗产 | 45岁之后 |

每柱包含两个部分：**天干**（Heavenly Stem）和**地支**（Earthly Branch），组成八个字——这就是"八字"名称的由来。

## 五行：万物的基石

八字的核心是**五行**（Wu Xing）——**木、火、土、金、水**。这些元素以相生相克的循环方式相互作用：

**相生循环**（哪个元素滋养哪个）：
- 木生火
- 火生土（化为灰烬）
- 土生金
- 金生水
- 水生木

**相克循环**（哪个元素克制哪个）：
- 木克土
- 土克水
- 水克火
- 火克金
- 金克木

你的八字命盘会计算你出生时刻这五个元素的平衡状态。某个元素过多或过少，都可以解释你人生中反复出现的模式。

## 日主：你的核心所在

你的八字命盘中最关键的部分是**日主**（日主，Rì Zhǔ）——即日柱的天干。它代表你的核心自我、你的先天性格。

共有**10种日主**，分别对应五行的阳性和阴性版本：

| 日主 | 五行 | 阴阳 | 性格特质 |
|-----------|---------|----------|-------------------|
| **甲（甲木）** | 阳木 | 阳 | 领导力、野心、开拓 |
| **乙（乙木）** | 阴木 | 阴 | 灵活、艺术、滋养 |
| **丙（丙火）** | 阳火 | 阳 | 魅力、热情、表达力强 |
| **丁（丁火）** | 阴火 | 阴 | 温和、温暖、精致 |
| **戊（戊土）** | 阳土 | 阳 | 稳重、可靠、有保护欲 |
| **己（己土）** | 阴土 | 阴 | 滋养、注重细节、体贴 |
| **庚（庚金）** | 阳金 | 阳 | 意志坚定、果断、坚韧 |
| **辛（辛金）** | 阴金 | 阴 | 优雅、精准、敏感 |
| **壬（壬水）** | 阳水 | 阳 | 适应力强、有战略思维、深沉 |
| **癸（癸水）** | 阴水 | 阴 | 直觉强、神秘、流动 |

了解自己的日主，有助于你认清自己的天然倾向，以及在什么样的环境中你能如鱼得水。

## 如何获取你的八字命盘

要计算你的八字命盘，你需要：

1. **出生年月日**
2. **出生时辰**（几点几分——非常重要！）
3. **出生地点**（用于真太阳时校正）
4. **性别**（影响大运排盘）

计算过程需要将你的公历出生日期转换为中国干支历的天干地支——这需要精确的天文数据。

## 八字 vs 西方占星术：关键区别

| 方面 | 西方占星术 | 八字（四柱命理） |
|--------|------------------|-------------------|
| **基础** | 行星与星座 | 时间柱与五行 |
| **命盘形式** | 圆形星盘 | 四列干支字符 |
| **核心概念** | 太阳星座 + 宫位 | 日主 + 五行 |
| **时间体系** | 太阳历（热带） | 节气 + 干支历 |
| **运势预测** | 行星运行 | 十年大运 |
| **文化起源** | 巴比伦 / 希腊 | 中国古代 |

两种体系都有各自的价值，但八字往往更加**确定性和结构化**——它不仅描述你的性格，还描绘你整个人生的能量周期。

## 为什么真太阳时很重要

准确计算八字的一个独特之处在于**真太阳时校正**。因为中国历法体系基于实际太阳位置，你的出生时间需要针对以下因素进行校正：

- **经度校正**：你所在地的本地时间与时区标准子午线的差异
- **时差方程**：一年中太阳日的自然变化

在北京下午2点出生和在洛杉矶下午2点出生的人，可能拥有不同的时柱，因为他们的太阳时是不同的。这就是为什么 FateWise 会为每一份命盘自动应用真太阳时校正。
